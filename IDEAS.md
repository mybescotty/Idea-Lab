# 💡 Idea Lab — Idea Board

**Anyone can add an idea here.** No download needed:

1. Click the ✏️ **pencil icon** (top right of this file on GitHub) to edit.
2. Copy the template below and paste it at the **bottom** of the "New ideas" section.
3. Fill it in — rough notes are fine!
4. Scroll down and click **Commit changes**.

Claude checks this file on a schedule. For each new idea it will create a project
overview and a plan for building it as an HTML app in the [`projects/`](projects/) folder,
then update the idea's **Status** below.

---

## ✍️ Template (copy this)

```
### Idea: <short name>
- **Submitted by:** <your name>
- **Date:** <YYYY-MM-DD>
- **What is it?** <one or two sentences>
- **Who is it for?** <who would use it>
- **Must-have features:**
  - <feature>
  - <feature>
- **Nice-to-have / notes:** <anything else, links, examples>
- **Status:** New
```

> Status values (Claude updates these): `New` → `Overview written` → `Building` → `Done`
